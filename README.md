#  أرواح فلسطين | Palestinian Souls

منصة ويب توثيقية وتفاعلية تهدف إلى تخليد أرواح شهداء فلسطين من خلال تمثيل بصري مهيب. يعرض الموقع سماءً افتراضية تمثل فيها كل نجمة مضيئة روحاً ارتقت، مع توفير واجهة متكاملة لسرد القصص، وعرض الإحصائيات، وتوثيق المحطات التاريخية المفصلية في تاريخ القضية الفلسطينية.

---

## 🌟 فكرة المشروع

يقدم هذا المشروع مساحة رقمية للذاكرة الفلسطينية، متجاوزاً لغة الأرقام المجردة ليمنح كل شهيد هويته واسمه. تم تصميم واجهة المستخدم لتكون تفاعلية، حيث يمكن للمستخدم استكشاف أسماء الشهداء بمجرد تمرير المؤشر فوق النجوم، والبحث في السجلات، ومشاركة بطاقات توثيقية للشهداء عبر منصات التواصل الاجتماعي.

---

## ✨ المميزات الأساسية

* **سماء الأرواح التفاعلية:** تمثيل بَصري باستخدام تقنية Canvas حيث تتجسد أرواح الشهداء كنجوم مشعة وتتخللها مؤثرات الشهب المتساقطة.
* **خريطة توثيقية جغرافية:** واجهة خرائط تفاعلية مبنية بمكتبة Leaflet لاستعراض السجلات وتوثيق الأحداث مكانياً.
* **الخط الزمني السينمائي:** قسم مخصص لسرد أبرز المحطات التاريخية والمجازر منذ ثورة البراق عام 1929، مروراً بالنكسة، وحتى الأحداث المعاصرة، مدعماً بالصور والإحصائيات.
* **لوحة الإحصائيات الشاملة:** رصد تفصيلي ومحدث باستمرار لآثار العدوان، يشمل الخسائر البشرية، تدمير البنية التحتية، المستشفيات، ودور العبادة.
* **تصنيفات التوثيق:** تقسيم منظم يشمل شهداء غزة، شهداء الصحافة، شهداء الضفة الغربية، وشهداء أراضي 48، بالإضافة إلى قسم مخصص للأرشيف المرئي والتقارير الإخبارية.
* **مشاركة البطاقات:** ميزة توليد ومشاركة بطاقات تعريفية لكل شهيد (الاسم، العمر، رقم الهوية).
* **تخصيص العرض:** دعم التبديل السلس بين الوضعين الليلي والنهاري، ودعم ثنائي اللغة (العربية والإنجليزية).
* **المؤثرات الصوتية:** خلفية صوتية تأملية قابلة للتشغيل والإيقاف لتعزيز التجربة الوجدانية للمستخدم.

---

## 🛠️ التقنيات والمكتبات المستخدمة

تم بناء المنصة بالاعتماد على هيكلية مرنة وتقنيات حديثة لضمان الأداء العالي والتجربة السلسة:

* **اللغات الأساسية:** HTML5, CSS3, JavaScript
* **أطر عمل التصميم:** Tailwind CSS و Bootstrap لتنسيق الواجهات التفاعلية بمرونة
* **التمثيل البصري والخرائط:** Leaflet.js للخرائط الجغرافية التفاعلية، وتقنية HTML5 Canvas لمحاكاة النجوم والشهب
* **الصوتيات ومعالجة الصور:** Howler.js لإدارة المؤثرات الصوتية، و HTML2Canvas لتوليد الصور
* **أدوات مساعدة:** jQuery لمعالجة بعض أحداث واجهة المستخدم
* **تحليلات الزوار:** ربط مع واجهة برمجة تطبيقات خارجية (CountAPI) لتتبع وعرض عدد الزوار
